# 🖋️ Academic Sandbox & Paper Archive

欢迎来到我的个人学术仓库！这里不仅仅用于存放我撰写的论文和草稿，更是我用来**刻意练习学术写作技巧、探索排版美学**的试验田。

相较于最终的发表成品，这个仓库更关注“过程”——从灵感捕捉、文献管理到最终生成完美的 PDF，这里记录了我在学术写作工具链上的不断折腾与优化。

## 🎯 仓库核心目的 (Why this repo?)

*   **📝 写作技巧沉淀**：记录如何构建论文逻辑、学术英语表达润色以及不同类型文章的结构框架。
*   **✨ LaTeX 魔法精进**：告别 Word，通过代码来控制排版。这里包含了各种自定义宏包、复杂表格、多图并排以及优美的数学公式实现方案。
*   **📊 绘图与数据可视化**：好图胜千言。这里会存放我使用各种工具（例如 TikZ, Matplotlib, Draw.io 或其他矢量图工具）生成高质量学术插图的源码和脚本。
*   **⚙️ 工作流自动化**：探索如何将 Zotero 文献库、代码脚本以及版本控制系统完美串联，打造属于极客的学术工作流。

## 📂 目录结构 (Directory Structure)

本仓库采用模块化管理，结构如下：

├── 📁 drafts/          # 正在撰写中的论文草稿与脑图
├── 📁 papers/          # 已完成或已发表的论文 (按年份/项目分类)
│   ├── 2026_Project_A/
│   └── ...
├── 📁 templates/       # 沉淀的优质 LaTeX 模板 (会议/期刊模板、简历等)
├── 📁 figures_lab/     # 绘图工具箱：存放各类画图脚本和源文件 (TikZ, Python 绘图代码等)
├── 📁 writing_tips/    # 学术写作笔记：好用的句型、语法指南、文献综述技巧
└── 📄 .gitignore       # 过滤掉 LaTeX 编译产生的中间文件 (如 .aux, .log, .out 等)

## 🛠️ 我的学术工具链 (Toolchain)

*   **排版与撰写**：LaTeX, Markdown
*   **文献管理**：Zotero
*   **版本控制**：Git & GitHub/Gitee
*   **前沿追踪**：arXiv 每日动态追踪
